# Contributing

This project is in planning/discovery. Read the first-pass brief and roadmap before proposing work. Small changes with explicit scope are welcome. Open an issue for major architectural changes.

Keep simulation rules independent of MCP and UI. Use the shared command layer, persist authoritative facts, and check retry/stale-state behavior. Add meaningful tests for engine invariants when executable code exists. No runtime or test commands exist yet.

Include source/license information for imported material. Never commit credentials, local campaign databases, player logs, or private settings. Do not add playable Americas content. Keep documentation clear about working features versus plans.

By submitting contributions, you agree to license your original contributions under the repository MIT license. Do not submit material you lack rights to redistribute.
